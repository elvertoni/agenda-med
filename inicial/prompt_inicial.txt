Estou desenvolvendo um novo projeto com Python e Django, que será um sistema web de agendamento para clínica médica que possui vários profissionais atendendo, quero um sistema que atenda pelo whatsapp com um chatbot capaz de consultar uma base de dados e agendas dos profissionais.
O cliente pode mandar uma mensagem, o chatbot interagem e responde as perguntas do cliente, pode passar informações sobre preço, protocolos de atendimento, protocolos de exames médicos, como jejum, o abstinência de determinados medicamentos ou alimentos mas tudo isso sera passado depois pela equipe da clinica.

Deve usar Django full stack, com frontend no próprio Django Template Language,
usando tailwindcss.
O design deve ser moderno e responsivo, com gradient de cores e paletas
harmônicas e fundo escuro.
Crie um padrão visual para o sistema todo. Todas as telas devem ter o mesmo
design e os mesmos componentes, seguindo uma identididade visual e um design
system.
O sistema de autenticação será o sistema nativo de usuários e autenticação
do Django.
O login de usuários deve ser feito através do email ao invés do username.
As entidades/domains do sistema devem ser separadas em apps do Django,
para isolar as responsabilidades.
O código deve ser simples, sempre usar aspas simples e seguir os padrões
da PEP08.
O código do projeto deve ser em inglês.
O código deve usar aspas simples sempre que possível.
Toda a informação mostrada na interface do usuário deve ser em português
brasileiro.
Usar apenas banco de dados sqlite padrão do Django.
Toda tabela/model deve ter os campos created_at e updated_at.
Não implementar docker inicialmente (colocar para sprints finais).
Não implementar testes inicialmente (colocar para sprints finais).
Sempre que possível, o projeto deve usar Class Based Views, classes, funções
e recursos nativos do Django.
Caso use signals no projeto, eles devem ficar em um arquivo signals.py dentro
da app correspondente do signal.
O sistema deve ter um site principal de apresentação que será público e terá
as opções de cadastre-se e login.
Após logar, o usuário é direcionado para o dashboard principal do sistema.
Não adicione nada além do que eu solicitar, o projeto deve ser simples e enxuto.

1 - o atendimento será primordialmente pelo whatsapp mas também o cliente pode entrar no site e verificar a disponibilidade da agenda e dos profissionais, bem como a consulta que marcou com confirmação através de um código enviado para o próprio whats da pessoa, exemplo, eu quero entrar no site, digito o meu whats que cadastrei a consulta e é enviado um código para o meu numero, com esse numero termino de acessar a plataforma.

2 - no cadastro da consulta devera ser solicitado e registrado as seguintes informações:
Nome completo, idade, sexo, endereço, numero celular, e-mail, plano de saúde e o que vc souber que é importante para agendamentos médicos.

3 - quero a capacidade de confirmação de presença com 24 horas de antecedência com confirmação do paciente pelo whatsapp e/ou e-mail.
